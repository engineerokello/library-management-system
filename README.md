# Library Management System

## Project Title

Library Management System Using Java

## Project Description

The Library Management System is a Java-based console application developed using Object-Oriented Programming (OOP) principles. The system enables students to borrow and return books, check book availability, calculate late return fines, and display the list of books borrowed by a student.

The project demonstrates the use of Java classes, objects, variables, methods, control structures, loops, arrays/lists, and basic user interaction through a menu-driven interface.

## Features

* Borrow books from the library.
* Return borrowed books.
* Check the availability status of books.
* Calculate fines for late returns.
* Display all books borrowed by a student.
* Enforce a maximum borrowing limit of five books.
* Prevent borrowing of unavailable books.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList Collection Framework
* Scanner Class for User Input

## Classes Used

### Book Class

Stores information about a book, including:

* Book title
* Availability status

### Student Class

Manages student operations, including:

* Borrowing books
* Returning books
* Calculating fines
* Displaying borrowed books

### LibraryManagementSystem Class

Contains the main method and menu-driven functionality for interacting with the system.

### Step 1: Clone the Repository

```bash

```bash

```bash
